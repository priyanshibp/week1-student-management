# Student Management System

A desktop-based Student Management System built using Python, Tkinter, and PostgreSQL.

The project allows student information to be managed through a graphical user interface and uses PostgreSQL as the database.

## Features

- Add new students
- View student records
- Search for students
- Update student information
- Delete student records
- Student reports
- Overall student statistics
- Average, youngest, and oldest age
- Students grouped by city
- Cities with more than one student
- Export student reports to a text file
- PostgreSQL database integration
- Course management using SQL
- Student course enrollment using SQL

## Technologies Used

- Python
- Tkinter
- PostgreSQL
- SQL
- pgAdmin 4
- Git
- GitHub
